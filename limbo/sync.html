LIMBO

Toca no botão grande (ou carrega no espaço) no momento em que cada verso começa. Enganaste-te? “Desfazer” (ou a tecla de apagar) volta um verso atrás.
Tap the big button (or press space) the moment each line starts. Missed one? “Undo” (or backspace) goes back a line.

Todas as canções já têm tempos feitos à máquina, que podem estar um ou dois segundos fora. Marca aqui só as que precisarem.
Every song already has machine-made times, which can be a second or two off. Tap along only the ones that need it.

Fica guardado neste aparelho, e o jogo neste aparelho já mostra os tempos. Para todos os verem: “Descarregar timings.js” no fim da página, e põe esse ficheiro na pasta limbo no GitHub (Add file › Upload files).
